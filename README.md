# Coders-of-India
Data cleaning and preprocessing using pure Python 

# Overview

This project focuses on cleaning and organizing raw social network data and preparing it for recommendation tasks such as:

People You May Know
Pages You Might Like

The dataset is processed from raw JSON files into cleaned and structured formats for further analysis or ML use.

# Data Cleaning Process

## The following preprocessing steps were applied:

Removed duplicate entries
Handled missing/null values
Standardized JSON structure
Filtered irrelevant or noisy data
Organized data for recommendation use cases

# Goal of the Project

## To transform raw social interaction data into a clean dataset that can be used for:

Recommendation systems
Data analysis
Machine learning models
